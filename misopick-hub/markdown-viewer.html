Tool #10

마크다운 미리보기 뷰어

마크다운(Markdown) 문법으로 작성한 텍스트를 입력하면 실시간으로 변환된 HTML 미리보기 화면을 확인하고 소스코드를 추출할 수 있습니다.

렌더링된 결과가 여기에 표시됩니다.

필수 마크다운(Markdown) 문법 가이드

마크다운은 텍스트 기호만을 이용하여 문서의 구조와 스타일을 간단히 지정하는 경량 마크업 언어입니다. 자주 쓰이는 핵심 문법 표현식은 다음과 같습니다.

제목 (Headers)

# H1, ## H2, ### H3

#의 개수로 <h1>부터 <h6>까지 대소제목을 구분합니다.

텍스트 강조 (Emphasis)

**굵게**, *기울임*, ~~취소선~~

특정 단어나 문장을 굵거나 이탤릭체로 강조할 때 감싸줍니다.

목록 (Lists)

- 순서없는 목록, 1. 순서있는 목록

하이픈(-) 또는 숫자를 사용하여 항목 리스트를 생성합니다.

인용 및 코드 (Quote & Code)

> 인용문, `인라인 코드`

> 키워드로 인용구를 표현하며, 백틱(`)으로 코드를 강조합니다.

마크다운 미리보기의 주요 활용 사례

GitHub README 및 오픈소스 문서 작성

개발 프로젝트 리포지토리의 README.md 파일이 정상적으로 가독성 있게 표현되는지 미리 검토할 수 있습니다.

기술 블로그 및 벨로그(Velog) 포스팅

마크다운을 지원하는 기술 블로그 플랫폼에 글을 등록하기 전, 문단 간격과 자간 및 코드가 잘 나오는지 확인합니다.

노션(Notion) 및 노션 가이드 정리

사내 위키, 노션 문서, 슬랙(Slack) 등의 메시지 작성 시 서식 표현을 실시간으로 확인하고 교정할 수 있습니다.

빠른 HTML 변환기 활용

마크다운 형태의 기획서나 원고를 깔끔한 웹 표준 HTML 소스 코드 태그로 즉시 변환하여 복사할 수 있습니다.

서비스 소개 및 이용 가이드

misopick.kr의 마크다운 미리보기 뷰어는 개발 문서, 블로그 포스팅, README 파일을 작성할 때 마크다운 문법이 웹상에서 어떻게 표현되는지 실시간으로 확인하고 HTML 코드로 변환할 수 있는 유용한 도구입니다.
