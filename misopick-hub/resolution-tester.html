화면 해상도 핵심 용어 가이드

웹 디자이너와 프론트엔드 개발자가 반응형 웹을 설계할 때 반드시 이해해야 하는 핵심 화면 규격 개념입니다.

뷰포트 (Viewport)

웹 브라우저에서 실제 콘텐츠가 그려지는 영역의 크기입니다. 미디어 쿼리(Media Query) 레이아웃 분기점의 기준이 됩니다.

화면 해상도 (Screen Resolution)

모니터나 스마트폰 하드웨어가 물리적으로 보유한 전체 가로·세로 픽셀 수입니다.

DPR (Device Pixel Ratio)

CSS 1픽셀을 구성하는 물리적 픽셀의 비율입니다. 레티나(Retina) 및 고해상도 디스플레이 구분에 활용됩니다.

대표적인 반응형 웹 브레이크포인트(Breakpoints)

모바일 (Mobile)

320px ~ 639px: 스마트폰 세로 모드 기준 영역입니다. 1단 칼럼 레이아웃과 햄버거 메뉴 구성을 권장합니다.

태블릿 (Tablet)

640px ~ 1023px: 아이패드, 갤럭시 탭 및 스마트폰 가로 모드입니다. 2단 그리드 배치가 효과적입니다.

노트북 및 소형 데스크톱

1024px ~ 1279px: 일반적인 노트북 해상도 범위입니다. 사이드바와 메인 컨텐츠 영역 분리 구성을 사용합니다.

대형 데스크톱 (Desktop)

1280px 이상: 고해상도 FHD, QHD, 4K 모니터 환경입니다. 컨텐츠 최대 너비(max-width)를 설정해 가독성을 높입니다.

서비스 소개 및 이용 가이드

misopick.kr의 화면 해상도 테스트 툴은 웹 퍼블리셔, 프론트엔드 개발자, 디자이너들이 각종 모바일, 태블릿, 데스크톱 기기 환경에 따른 뷰포트 크기와 해상도 스펙을 간편하게 테스트하고 진단할 수 있도록 지원합니다.

자주 하는 질문 (FAQ)

화면 해상도는 디스플레이의 물리적 전체 픽셀 수이며, 뷰포트는 브라우저 창에서 웹페이지가 실제로 표시되는 영역의 크기를 의미합니다. 반응형 웹 디자인 시 뷰포트 크기 기준으로 레이아웃이 조절됩니다.
아니요, 전혀 저장되지 않습니다. 브라우저 내장 자바스크립트 객체를 통해 실시간으로 측정되므로 프라이버시가 완벽히 보호됩니다.
네, 스마트폰이나 태블릿 브라우저로 접속 시 현재 기기의 실시간 뷰포트 크기와 픽셀 밀도(DPR)를 정확하게 조회할 수 있습니다.
네, 브라우저 창의 크기를 변경하면 resize 이벤트가 감지되어 뷰포트 수치가 즉각 갱신되므로 실시간으로 반응형 크기를 파악할 수 있습니다.
