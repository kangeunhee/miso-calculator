텍스트 암호화/복호화 활용 가이드

텍스트 암호화(Text Encryption)는 소중한 개인 정보, 비밀번호, 금융 메모, 보안 메시지를 다른 사람이 알아보지 못하도록 난독화된 문자열로 변환하는 기술입니다. 본 툴은 표준 보안 방식인 AES-256 (Advanced Encryption Standard)을 지원하여 강력한 보안성을 보장합니다.

강력한 AES-256 보안

미국 정부 표준 알고리즘으로 본인만의 비밀키가 없으면 복원 불가능.

클라이언트 사이드 처리

입력한 메시지와 비밀키는 서버로 전송되지 않고 브라우저 내에서 즉시 암호화.

안전한 비밀 전달

암호문과 비밀키를 별도의 경로로 전달하여 메신저 해킹 피해 예방.

지원 알고리즘 방식

  • AES-256: 가장 널리 쓰이는 대칭키 암호화 방식으로, 동일한 비밀키(Passphrase)가 있어야만 복호화할 수 있습니다.
  • Base64: 이진 데이터를 텍스트로 인코딩/디코딩하는 방식으로, 데이터 송수신 안정성에 유용합니다.
  • Caesar Cipher (시저 암호): 알파벳 글자를 일정 간격만큼 이동시키는 고전적인 암호화 방식입니다.

자주 묻는 질문 (FAQ)

Q. 비밀키를 잊어버리면 어떻게 되나요?
A. AES-256 암호화 알고리즘 특성상 비밀키를 분실한 경우 원문을 복원할 수 있는 방법이 절대 존재하지 않습니다. 반드시 비밀키를 기억해 두세요.

Q. 내가 입력한 내용이 서버에 저장되나요?
A. 절대 저장되지 않습니다! 모든 연산은 사용자의 웹 브라우저 메모리 내 자바스크립트로 동작하므로 외부 전송이 발생하지 않습니다.
